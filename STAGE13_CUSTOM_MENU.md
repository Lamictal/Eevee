# Stage 13: custom Eevee main menu

The **New Game / Continue / Options** menu now has an original Eevee-themed background and clearer labels. This is a real GBA background asset, built into the ROM from a reproducible Python art generator. It is **not a static website mockup**.

## Visual design

- Midnight/navy/lilac backdrop with stars, gold and teal highlights.
- Original hand-coded Eevee-inspired fox silhouette, pale ruff and star motif.
- **EEVEE / 171 FORMS** in the lower part of the screen.
- **NEW JOURNEY** replaces the visible `NEW GAME` label.
- **SETTINGS** replaces the visible `OPTION` label.
- Continue, Mystery Gift and save summary retain their existing names and screen layout.

The art is an original asset generated by `stage13_custom_menu.py`, not copied from any third-party `Oops! All Eevees!` illustration. This distinction will help with eventual public game-art permissions.

## Implementation details

- The asset generator uses the existing GBA **BG1** background layer behind the normal menu windows on **BG0**.
- It builds a 4bpp, 16-color-tile background and a 32×32 tile map. Repeated tiles are deduplicated to stay clear of BG1's screenblock 7.
- The new palette occupies BG palette bank 1, separate from the main menu's text palette 15 and window frame palette 2.
- Existing menu input and callbacks, save-file detection, options return behavior, game intro, and error screens are untouched.
- It changes no species, save block, evolution, encounter or item data.

## Acceptance tests before Beta 1

1. New save: start up and check the menu background shows without tile corruption.
2. Select **NEW JOURNEY**, confirm it starts Birch's introduction.
3. Save and reboot; verify **CONTINUE** and the save-file summary remain available.
4. Visit **SETTINGS**, change an option and return to the menu.
5. Test B returning to the title screen.
6. Confirm Mystery Gift and error-menu variants still respond normally.
