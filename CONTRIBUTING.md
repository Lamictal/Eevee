# Reporting issues and contributing

This is a small, independently maintained Pokémon Emerald Expansion fan project.

## Playing and feedback
- **[Get the current alpha](DOWNLOAD.md)** (the repository is public; downloadable test builds are temporary GitHub Actions artifacts).
- **[Report a bug](https://github.com/Lamictal/Eevee/issues/new/choose)** with the build link, emulator, save status and reproducible steps.
- Suggestions for improvements are welcome as issues or pull requests.

## Can other people edit the original?
No. Making a GitHub repository **public** allows people to view, download, fork, or suggest changes. Direct edits and merges into the original repository require explicit **write permission** from its owner. Don't grant collaborators write access merely so they can play.

## Art and third-party materials
This repository includes or builds on third-party Pokémon game data, *Oops! All Eevees!* artwork and the open-source [pokeemerald-expansion](https://github.com/rh-hideout/pokeemerald-expansion) engine. Before proposing publicly distributed files, check relevant copyright and license terms. Avoid uploading copyrighted base ROMs, other people's game art without permission, personal game saves or secrets.

There is deliberately **no blanket license** claiming ownership of Nintendo's IP or the source artwork. Credits and applicable upstream license notices must be preserved.
